title: Skills
description: Every skill the Cardea plugin ships, and the skills Cardea installs from elsewhere.
---

Skills load when a task calls for them, so unlike the rules in `CLAUDE.md` they cost nothing
until they are used. Cardea ships its own as part of the [Cardea plugin](/docs/claude-code#the-cardea-plugin).

## Workflow and agents

| Skill | What it does |
|---|---|
| `retrieval-order` | Sets the order to look things up in: session, rules, Basic Memory, the active plan, graphify, the code, git history, live evidence, docs, the web, then you |
| `handoff` | Hands the session over to a fresh one before autocompact: writes a summary, starts a new session in a new herdr tab and closes the old pane |
| `herdr` | Cardea's herdr house rules: the two-column batch layout, agent names, start lines with Langfuse tags, background waits, error handling and pane etiquette |
| `blind-port` | Ports a UI to another framework without the implementer seeing the original; see [Blind port](/docs/blind-port) |
| `panel` | Puts a design question to a UX designer, the average chud and a power user, then merges their verdicts into one recommendation |
| `post-merge-sweep` | Clears herdr panes and tabs, git worktrees and branches, simulator clones and orphaned build data after work merges to main |

## Code quality and releases

| Skill | What it does |
|---|---|
| `comment-audit` | The comment rules and the five-step audit that enforces them on every changed file |
| `pre-commit-audit` | Comment audit, docs, affected tests, a clean zero-warning build and hygiene checks, ending in a fixed report |
| `semantic-commit` | Creates a conventional commit from staged changes |
| `local-merge` | Merges a branch into main locally when CI is unavailable: runs the CI test command, then squash merges, pushes main and deletes the branch |
| `release-changelog` | Cuts a release: bumps the app version, writes the changelog entry, runs the checks, merges and pushes an annotated tag |
| `ux-writing` | The house rules for user-facing app copy |
| `mermaid` | The house rules for Mermaid diagrams, and how to open one in mermaid.live |

## Apple and Swift

| Skill | What it does |
|---|---|
| `rendering-swiftui-previews` | Renders a SwiftUI view or `#Preview` as an image without opening the Xcode canvas |
| `sim-clone-restore` | Gives a task its own simulator holding real app data, by cloning a golden simulator or restoring a backup, and deletes it afterwards |
| `grdb` | GRDB.swift v7 best practices for SQLite in Swift |

## Notes and the self-hosted stack

| Skill | What it does |
|---|---|
| `basic-memory` | Reads and writes durable notes in Basic Memory on the NAS |
| `obsidian` | How you read and edit the notes vault in Obsidian |
| `langfuse` | Cardea's Langfuse tracing: looking up an earlier session or trace, and why tracing may be missing |
| `graphify` | When and how to use graphify, the local code knowledge graph |

## Skills Cardea installs from elsewhere

| Skill | Where it comes from |
|---|---|
| `tldr`, `baby` | The repo's own `claude/skills/`, linked into `~/.claude/skills/` |
| `herdr`, `graphify`, `playwright-cli` | Generated by `scripts/vendor-skills.sh` from the installed versions; the vendored `herdr` covers the CLI, while the Cardea `herdr` skill covers the house rules |
| `marimo-notebook` | Copied from the latest `marimo-team/skills` |
| `langfuse` | Copied from the latest `langfuse/skills`; it covers Langfuse itself, while the Cardea `langfuse` skill covers this setup's tracing |

The [marketplace plugins](/docs/claude-code#marketplace-plugins) add skills of their own.
