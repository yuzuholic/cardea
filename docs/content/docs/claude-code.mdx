Claude Code keeps its own state next to its settings: sessions, plugin caches, and the list
of MCP servers. Cardea therefore never links a whole folder. It owns a few named things and
leaves everything else to you.

## What Cardea owns

| Thing | Where it lives | How it gets there |
|---|---|---|
| Global rules | `~/.claude/CLAUDE.md` | Symlink to `claude/CLAUDE.md` |
| tldr skill | `~/.claude/skills/tldr/` | Symlink to `claude/skills/tldr/` |
| baby skill | `~/.claude/skills/baby/` | Symlink to `claude/skills/baby/` |
| MCP servers | User scope in `~/.claude.json` | `claude mcp add-json --scope user` |
| Plannotator | Plugin, plus the `plannotator` binary | Plugin marketplace, binary installer |
| Langfuse tracing | Plugin | Plugin marketplace, configured from `.env` |
| Cardea plugin | Plugin, a copy in `~/.claude/plugins/cache/` | `claude plugin install` from the repo |
| Five more plugins | Plugins | Their own marketplaces |
| herdr, graphify, playwright-cli, marimo and langfuse skills | `~/.claude/skills/herdr/`, `~/.claude/skills/graphify/`, `~/.claude/skills/playwright-cli/`, `~/.claude/skills/marimo-notebook/`, `~/.claude/skills/langfuse/` | `scripts/vendor-skills.sh` |
| Playwright CLI | The `playwright-cli` binary, with Chromium | `npm install -g @playwright/cli@0.1.24`, then `playwright-cli install-browser chromium` |

## What Cardea leaves alone

- `~/.claude/settings.json`: your hooks, permissions and preferences.
- Your other skills in `~/.claude/skills/`, and any other plugins.
- MCP servers with names Cardea does not use.

## Plugins

**Plannotator** opens plans in a review UI before Claude acts on them. The plugin only adds
hooks; those hooks call the `plannotator` binary, which the script installs on its own at a
pinned version.

**Langfuse** sends each turn to Langfuse after it finishes: your prompt, Claude's reply,
every tool call, and timing, grouped by session. The script always points it at the NAS, even
before there are keys, so it never falls back to Langfuse's hosted service. The secret key is
passed on standard input, kept out of the process list, and stored in the macOS keychain.

## The Cardea plugin

Cardea's own skills and agents ship as a Claude Code plugin. Skills load when a task calls
for them, so unlike the rules in `CLAUDE.md` they cost nothing until they are used.

Every skill is listed, with what it does, on [Skills](/docs/skills).

`retrieval-order` sets where an agent looks before it asks: the session, then the rules and
memory, Basic Memory, the active plan, graphify, the code, git history, tests and
builds, skills and offline docs, the web, and you last. Notes and history answer why
something is the way it is; the code and live results answer what it is now, and win when a
note is out of date.

The plugin's agents, including the three design panel agents, are on [Agents](/docs/agents).

`install.sh` installs the plugin from your checkout. Claude Code keeps its own copy, in
`~/.claude/plugins/cache/cardea/cardea/<version>/`, so an edit in the repo does nothing until
you refresh that copy and start a new session. Rerunning `./install.sh` updates the Cardea
plugin and every marketplace plugin. For a quick refresh after an edit, update just this one:

```sh
claude plugin update cardea@cardea
```

The repo is private, so installing the plugin anywhere else needs access to it. With access:

```sh
claude plugin marketplace add yuzuholic/cardea
claude plugin install cardea@cardea
```

## Hooks

The plugin also ships six hooks. Three can block a tool call, and the commit hook can also ask
you first; the other three only add a note. If a hook fails for any reason, the call goes
ahead. None of them ever approves a call, so your usual permission prompts still apply.

| Hook | When | What it does |
|---|---|---|
| Session note | A session starts, resumes or is compacted | Reminds Claude of the lookup order, names the repo's Basic Memory project (the repo's folder name), says whether a graphify map exists, and lists up to five notes from the last week. If the NAS doesn't answer within 1.5 seconds, the notes are left out. |
| Secrets | Before reading, searching, editing or running a command | Blocks private keys (`id_rsa`, `*.pem`, `*.key`, `*.p12`, `*.p8`). `*.pub` keys are fine, and so are `.env` files: what's in them can be rotated, and production secrets live in GitHub and CI. |
| Blind mode | Before reading, searching, editing, fetching or running a command, only when `CARDEA_BLIND=1` | Denies reads of the paths in `CARDEA_BLIND_PATHS` and the URLs in `CARDEA_BLIND_URLS`, of `dist/`, `build/`, `.next/` and `storybook-static/`, `playwright-cli`, AXe and `simctl` screenshot commands, and browser or screenshot MCP tools. A deny never prompts you. Only the blind implementer is started with the variables. |
| Commit message | Before a `git` command | Blocks a commit whose message isn't `<type>: <subject>`: lowercase, no full stop, under 72 characters, no body and no trailers such as `Co-Authored-By`. It lists what's wrong. If the message can't be read, for example because an editor opens, the commit goes ahead. Outside the cardea repo, it also checks the message and the lines being committed for any mention of an AI tool or company, and asks you to approve that one commit when it finds one, listing each file, line and word. Every commit is asked fresh. |
| Web nudge | The first web search or fetch in a session | Reminds Claude to check notes, code and history first. It never blocks. |
| Handoff nudge | The first message after the context passes 195k tokens | Asks Claude to propose a handoff to a fresh session with the `handoff` skill, ten points before autocompact at 75% of the 300k window. It reads the size from the session's transcript and never blocks. |

The secrets check on commands is a scan of the words in the command, so it misses some
routes: a variable holding the path, `git show HEAD:id_rsa`, or `grep -r` across a folder. It
stops accidents, not someone trying to get round it.

## Marketplace plugins

The script installs these from their own marketplaces. On a rerun it switches back on any
that were turned off and updates each one.

| Plugin | What it adds |
|---|---|
| [superpowers](https://github.com/obra/superpowers-marketplace) | Working habits: brainstorming, plans, TDD, systematic debugging, code review |
| [ponytail](https://github.com/DietrichGebert/ponytail) | Pushes toward the simplest solution that works |
| [apple-skills](https://github.com/Prisma-Labs-Dev/apple-skills) | Apple API references: SwiftUI, UIKit, SwiftData and more |
| [cloudflare](https://github.com/cloudflare/skills) | Guidance for building on Cloudflare |
| [humanizer](https://github.com/blader/humanizer) | Rewrites text that reads as machine-written |

herdr, graphify and playwright-cli each ship a skill of their own. `scripts/vendor-skills.sh`
generates all three from the installed versions on every run, so they always match. graphify's installer would
also edit `CLAUDE.md`; the script runs it against a scratch folder so the real one is never
touched. marimo and Langfuse publish their skills in git repos, so the script copies the
`marimo-notebook` skill from the latest `marimo-team/skills` and the `langfuse` skill from the
latest `langfuse/skills`. The `langfuse` skill covers Langfuse itself: its API, docs and
instrumenting an app. cardea's own `langfuse` skill covers this setup's tracing.

## Decisions you make

When a decision is yours to make, Claude asks in the chat, one question at a time, following
the rules in `claude/CLAUDE.md`:

1. It explains the problem simply and lists the questions coming.
2. Each question comes as "Q1 of 3". It says what it decides in a sentence or two, then shows a
   table of options with short cells for what is good and not good about each. One is marked
   **(recommended)**. A one-line pick gives the reason and names the cheapest option that has no
   real downside. Jargon is explained in brackets, and side notes come last.
3. It confirms your answer in one line and waits for "next". "Go with yours" accepts the
   recommendation.
4. At the end it sums up every decision and waits for your go before acting.
5. Each decision is saved to Basic Memory.

Choices with an obvious default don't get a question; Claude goes ahead and mentions it in
one line.

## Your subscription, not an API key

Claude Code uses your Claude subscription login. If `ANTHROPIC_API_KEY` is set in your shell,
Claude Code uses that instead and bills the API. `./install.sh --check` warns when it is set.
