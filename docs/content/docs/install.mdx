`install.sh` is safe to run as often as you like. Each run brings the machine back in line
with the repo and finishes by checking that everything actually answers.

| Flag | Effect |
|---|---|
| *(none)* | Ask for each value, showing the current one as the default. Enter keeps it. |
| `--no-prompt` | Ask nothing; keep whatever `.env` already holds. For unattended runs. |
| `--check` | Check tools and services, then exit. Changes nothing. |

## What a run does

1. **Packages.** Applies the `Brewfile`. Third-party taps are trusted first, because
   Homebrew 7 refuses them otherwise. A failed package shows as a failure, not a tick.
2. **Configuration.** Asks for the NAS and Langfuse addresses and the Langfuse keys,
   then writes them to `.env` (mode 600, never committed).
3. **Rules.** Links `claude/CLAUDE.md` to `~/.claude/CLAUDE.md`.
4. **Claude Code.** Installed by the `Brewfile` as `claude-code`, the stable channel. The script then
   registers the MCP servers and plugins. See [Claude Code](/docs/claude-code). It also turns
   on the task list (`CLAUDE_CODE_ENABLE_TODO_TOOLS`) in `~/.claude/settings.json` and adds Hindsight's
   `delete_document` to `permissions.allow`, so that call doesn't wait on a prompt.
5. **herdr.** Installs herdr's Claude Code integration.
6. **Installs in parallel.** Plugins, graphify, Playwright CLI with Chromium, the vendored
   skills and the MCP servers run side by side. Those that need no answers start before the
   prompts. Under gum the run shows one live line per job with its time; otherwise it prints
   one line as each job finishes. Each job logs to its own file. A failed job shows the end of
   its log, the others still finish, and the script exits non-zero.
7. **Checks.** Confirms each tool (including `pnpm`, `gh`, `jq` and the Docker daemon, which
   OrbStack provides) is installed, each NAS service answers, and each MCP server connects.
   It warns when `~/.local/bin`, where graphify installs, is not on `PATH`, and
   ends with a count of what passed, warned and failed.
8. **Fixes.** Offers to fix each warning the script can: add `~/.local/bin` to `PATH` in your shell
   profile, open OrbStack when the Docker daemon is down, retry herdr's integration, and delete a
   native `claude` that shadows Homebrew's (default no). One yes/no question each, after the count.
   A last question, default yes, sets `agent` in `~/.claude/settings.json` so a plain `claude`
   starts as `cardea:orchestrator`; answering no removes the key only if it holds that value, and
   an explicit `--agent` flag still wins. A yes also adds a comment and two `export` lines to your
   shell profile (`CC_LANGFUSE_TRACE_TAGS` and `LANGFUSE_TRACING_ENVIRONMENT`, each defaulting to
   the orchestrator) so Langfuse labels hand-started sessions; a no removes exactly those lines.
   `--check` shows the current default agent.
   `--check`, `--no-prompt` and runs without a terminal never ask and never change anything.

## Answering the prompts

Type as little as you like. `192.0.2.10` becomes `http://192.0.2.10` as `NAS_URL`, the
Hindsight address is derived from it, and Langfuse then defaults to the same machine on port 3000. A full address
starting with `http://` is kept exactly as typed. An address ending in `.local` is kept, with
a warning that it can stall; see [Use a fixed address](/docs/nas#use-a-fixed-address).

Each address is tested the moment you enter it. If the test fails, the prompt asks again:

- **Enter** tests the same address again.
- **A new address** tests that one instead.
- **`skip`** (or Ctrl-D) keeps the address untested and moves on. Use it when a service is
  down on purpose; `./install.sh --check` tests it again later.

Keys are typed hidden. Leaving the Langfuse keys blank is fine: tracing simply stays off
until you add them and run the script again.

The tests ask each service something it has to understand. Langfuse must answer `200` on `/api/public/health`.

## Nothing gets overwritten

If a real file is already where a link should go, it is moved to `backup/<timestamp>/`
first. That includes an existing `~/.claude/CLAUDE.md`.

<Callout type="warn" title="Move project rules out first">
  If `~/.claude/CLAUDE.md` currently holds rules for one project, move them into that
  project's own `CLAUDE.md` before running the script. Otherwise they stop loading until you do.
</Callout>

## Piping from curl

Prompts read from `/dev/tty`, not standard input, so `curl … | sh` can still ask questions.
The whole script is wrapped so the shell reads all of it before running any of it; without
that, Homebrew would swallow the rest of the script mid-run.

## Windows

`install.ps1` is the Windows counterpart. It links the global rules and the `tldr` and `baby`
skills, registers the Hindsight MCP server, and installs the plugins.
It does not set the Hindsight allow rule or the default agent.

Prerequisites:

- Git for Windows, with Git Bash
- Python 3: `winget install Python.Python.3.13`
- uv: `winget install astral-sh.uv`
- pnpm: `winget install pnpm.pnpm`
- GitHub CLI: `winget install GitHub.cli`
- Claude Code
- Developer Mode (Settings > System > For developers), or an elevated PowerShell, so links can be created

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

`pwsh -File .\install.ps1` works the same under PowerShell 7. Add `-Check` to report
prerequisites and links without changing anything. Hindsight is registered only when `.env`
holds `NAS_URL` and `HINDSIGHT_MCP_TOKEN`. A `.env` with only `BASIC_MEMORY_URL` still works for one release: `NAS_URL` is derived from it.

## After installing

```sh
claude auth login        # sign in with your Claude subscription
xcode-build-server config -project MyApp.xcodeproj -scheme MyApp   # once per iOS project
```

SourceKit-LSP, the Swift language server, reads the `buildServer.json` that second command writes.
