Homebrew installs the current version of a formula. It cannot hold an exact one, so the brew
rows move when their makers release.

Claude Code comes from Homebrew's `claude-code` cask, which follows Anthropic's stable
channel. The `claude-code@latest` cask follows the newest release instead; the two conflict, so
only one can be installed. Don't also
use Anthropic's native installer: it puts a second copy in `~/.local/bin`, which comes first
on `PATH` and updates itself separately. The install script warns if it finds one.
