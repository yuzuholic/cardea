---
title: MCP
description: The MCP servers install.sh registers, what each is for and where it runs.
---

Registered at user scope in `~/.claude.json`, so every project gets them. Each run removes and
re-adds them, which keeps them in line with the script.

| Name | What it is for | Where it runs | Command |
|---|---|---|---|
| <Tool icon="xcode.svg" mono>`xcodebuild`</Tool> | Builds, tests and runs iOS apps | Local | `npx -y xcodebuildmcp@2.7.0 mcp` |
| <Tool icon="swift.svg" mono>`swiftlens`</Tool> | Swift symbol lookups | Local | `uvx swiftlens@0.2.14` |
| <Tool icon="xcode.svg" mono>`xcode`</Tool> | Apple's bridge into a running Xcode | Local | `xcrun mcpbridge` |
| <Tool icon="basic-memory.png">`basic-memory`</Tool> | Durable notes | NAS | HTTP, the URL from `.env` |

Values come from `.env` when the script runs. After changing `.env`, run the script again.
Without a Basic Memory URL in `.env`, the script skips `basic-memory`.

The Xcode bridge only connects while Xcode is open, so Claude Code reports it as failed the
rest of the time. That is expected.

Cardea leaves MCP servers with other names alone.
