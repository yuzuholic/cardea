Cardea was the Roman goddess of the door hinge. Forculus had the door, Limentinus the
threshold, Cardea the thing that lets it swing. This repo is the hinge: one command sets up
Claude Code on a Mac, wires it to its tools, and points it at the services running on the NAS.

## Two ways in

Cardea has two entry points, each with its own settings file.

### The Mac: `install.sh`

Installs Claude Code and everything around it. It asks for the Basic Memory and Langfuse
addresses and the Langfuse keys (listed in `.env.example`) and keeps them in `.env`.

```sh
git clone https://github.com/yuzuholic/cardea.git ~/Repositories/cardea
cd ~/Repositories/cardea
./install.sh
```

Or, on a fresh machine:

```sh
curl -fsSL https://raw.githubusercontent.com/yuzuholic/cardea/main/install.sh | sh
```

### The NAS: `nas/compose.yml`

Runs the services Claude Code talks to, self-hosted, as one service. Put `compose.yml`, a
`.env` filled in from `nas/.env.example`, and `kb/` in one folder on the NAS, then:

```sh
sudo docker compose up -d
```

[NAS](/docs/nas) covers the secrets, ports and updates.

<Callout title="Before you start">
  Install Xcode 26.3 or later and keep it running. The Xcode bridge only connects while Xcode
  is open, and Xcode cannot be installed by a script.
</Callout>

## What you get

- **Claude Code**, signed in with your Claude subscription.
- **Global rules** from `claude/CLAUDE.md`, linked into `~/.claude/`.
- **Five [MCP servers](/docs/mcp)** registered for every project: XcodeBuildMCP, SwiftLens,
  the Xcode bridge, container-use and Basic Memory.
- **[Skills](/docs/skills) and [agents](/docs/agents)** from the Cardea plugin.
- **Two plugins**: Plannotator for reviewing plans, and Langfuse for tracing every session.
- **The NAS services** those talk to: Basic Memory and Langfuse, started on the NAS by
  `nas/compose.yml`.
